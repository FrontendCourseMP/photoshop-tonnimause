# Photoshop

Волков Роман Сергеевич, группа 221-322. GitHub: [tonnimause](https://github.com/tonnimause).

Сайт: [tonnimause-photoshop.onrender.com](https://tonnimause-photoshop.onrender.com).

Учебный редактор изображений в браузере. Можно открыть PNG, JPG или GB7, изменить размер картинки, выбрать цвет пипеткой, поработать со слоями, применить коррекцию или фильтр.

Размер и глубина цвета показаны внизу, рядом можно менять масштаб просмотра. Для изменения самого размера картинки есть отдельное окно с настройками в пикселях и процентах.

Используются React, TypeScript, Ant Design и SCSS. Проект собирается через Vite.

## Запуск на компьютере

Для запуска необходимы Node.js и npm. Открыть терминал в папке проекта и выполнить команды:

```bash
npm ci
npm run dev
```

После запуска перейти в браузере по ссылке из терминала.

Для сборки: `npm run build`. Готовые файлы появятся в `dist`, посмотреть сборку можно через `npm run preview`.
