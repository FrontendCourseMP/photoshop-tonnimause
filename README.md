# Цифровое представление изображения

Волков Роман Сергеевич, группа 221-322. GitHub: [tonnimause](https://github.com/tonnimause).

Приложение открывает PNG, JPG и GB7 и показывает изображение на canvas. Внизу указаны исходные размеры и глубина цвета. Изображение можно вписать в рабочую область или просмотреть в масштабе 100% с прокруткой.

Кнопка «Сохранить» открывает выбор формата PNG, JPG или GB7. Сохраняется полный размер изображения, независимо от масштаба просмотра.

## Масштаб просмотра

Масштаб от 12 до 300 процентов задаётся ползунком внизу. Рядом выбирается интерполяция: билинейная по умолчанию или ближайший сосед. Оба метода реализованы в приложении. Масштаб меняет только просмотр, не размеры сохраняемого изображения.

Кнопка «Вписать» размещает изображение по центру с отступами от 50 пикселей. Если оно не помещается даже при 12 процентах, используется прокрутка. Кнопка «100%» возвращает натуральный размер. При большом увеличении приложение рисует видимый фрагмент, не выделяя память под всё увеличенное изображение.

## Изменение размера

Кнопка «Размер изображения» открывает отдельное окно. Указать ширину и высоту в пикселях или процентах, при необходимости отключить связь пропорций и выбрать интерполяцию. В окне указано число пикселей до и после операции; описание алгоритма доступно по кнопке «Об алгоритме».

Изменение размера, в отличие от масштаба просмотра, меняет сам массив пикселей и размеры скачиваемого файла. Текущий процент просмотра сохраняется. Применение недоступно при неверных размерах или превышении лимита 24 Мп и 16 384 пикселей по стороне. «Отмена» и Escape закрывают окно без изменения изображения.

## Каналы

Панель каналов находится справа от холста, на узком экране — под ним. Нажатие на канал включает или выключает его отображение. Превью показывают интенсивность отдельного канала в оттенках серого, независимо от его состояния.

Для серого изображения доступен один цветовой канал, для RGB — три. При наличии прозрачности появляется отдельный канал: альфа, маска GB7 или прозрачность PNG из палитры либо цветового ключа. Если оставить только этот канал, холст показывает чёрно-белую маску. Отключение прозрачности делает изображение непрозрачным; отключение всех каналов оставляет пустой прозрачный холст.

Переключение каналов не изменяет исходные пиксели и сохраняемый файл. При открытии другого изображения все его каналы включаются.

## Пипетка

Включить кнопку «Пипетка» и выбрать пиксель левой кнопкой мыши на холсте. Под изображением отображаются X и Y от верхнего левого угла с нуля, значения RGB от 0 до 255 и координаты CIELAB с точкой белого D50. Масштаб просмотра и прокрутка учитываются при выборе пикселя.

Пипетка читает исходный декодированный массив, а не изображение с отключёнными каналами. Для PNG и JPEG это 8-битные значения sRGB, полученные от браузера, а не исходные 16-битные компоненты файла. RGB полностью прозрачного PNG браузер может обнулить при декодировании; восстановить утраченные значения нельзя. В GB7 скрытые значения серого сохраняются собственным декодером. Цветовой образец показывается без наложения прозрачности на фон.

Преобразование CIELAB реализовано в приложении: линеаризация sRGB, XYZ с адаптацией Bradford к D50, затем L*a*b*. Описание преобразований — [CSS Color 4](https://www.w3.org/TR/css-color-4/#color-conversion-code).

## Уровни

Кнопка «Уровни» открывает гистограмму и настройки чёрной точки, белой точки и гаммы. Master изменяет цветовые компоненты вместе; отдельные каналы, включая прозрачность, настраиваются независимо. Параметры сохраняются при переключении каналов.

Предпросмотр включён по умолчанию. Снять флажок для сравнения с изображением до открытия диалога. «Сброс» возвращает настройки всех каналов к нейтральным, «Отмена» и Escape закрывают окно без изменений. «Применить» сохраняет коррекцию в текущем изображении, даже если предпросмотр выключен. После применения пипетка, миниатюры каналов и скачивание используют изменённые пиксели. Сведения в строке состояния по-прежнему относятся к исходному файлу.

Общая гистограмма рассчитывается по относительной светлоте с линеаризацией sRGB, поканальные — по значениям компонентов. Логарифмический режим меняет только высоту столбцов. Для GB7 шкала содержит 128 уровней, для PNG и JPG — 256. Порядок коррекции: Master, затем настройки отдельных цветовых каналов; альфа обрабатывается отдельно.

## Запуск

Необходимы Node.js 24 и npm. Открыть терминал в папке `project` и выполнить:

```bash
npm ci
npm run dev
```

Перейти по адресу из терминала. Для сборки выполнить `npm run build`, для просмотра сборки — `npm run preview`.

## Проверки

```bash
npm run test:run
npm run lint
npm run type-check
```

Проверка интерфейса в браузере:

```bash
npx playwright install chromium
npm run test:browser
npm run test:production
```

Глубина цвета читается из заголовка исходного файла, а не из RGBA-буфера canvas. Альфа указывается отдельно. Для PNG с палитрой показывается разрядность индекса палитры; прозрачность через `tRNS` не считается отдельным альфа-каналом. JPEG с четырьмя цветовыми компонентами также не считается изображением с альфой. Для GB7 показываются 7 бит цвета и, при её наличии, маска 1 бит.

PNG и JPEG декодируются средствами браузера. При отображении 16-битного PNG браузер переводит значения в свой буфер; сведения об исходной разрядности сохраняются. При наличии EXIF-ориентации браузер может повернуть изображение для просмотра, при этом строка состояния показывает размеры из заголовка.

Ограничения загрузки: 50 МБ, 24 миллиона пикселей, не более 16 384 пикселей по стороне.

## Сохранение

- PNG сохраняет пиксели и прозрачность текущего изображения без сжатия с потерями.
- JPG использует выбранное качество сжатия. Прозрачные участки объединяются с белым фоном.
- GB7 переводит изображение в 128 оттенков серого. Можно сохранить бинарную маску или объединить прозрачность с белым фоном.

GB7 реализован самостоятельно по заданию: заголовок 12 байт, размеры в big-endian, младшие 7 бит — серый, старший бит — маска. Значение маски 0 означает прозрачный пиксель, 1 — непрозрачный. Без флага маски старший бит равен 0. В тексте задания есть противоречие о номере бита; использована эта схема, указанная в описании структуры пикселя.

При преобразовании RGB в серый используются веса 0,299 для красного, 0,587 для зелёного и 0,114 для синего, затем округление до диапазона 0–127. При записи маски альфа меньше 128 становится нулём, от 128 — единицей.

Учебные образцы GB7 находятся в `tests/fixtures/gb7`. Все три файла проверены на загрузку и побайтовое совпадение после сохранения. В `tests/fixtures/images` находятся PNG и JPG для проверки глубины цвета, прозрачности, EXIF-ориентации и размеров до 3840 × 2160.

## Публикация

Адрес проекта на Render: [tonnimause-photoshop.onrender.com](https://tonnimause-photoshop.onrender.com).

Для Static Site указать ветку `main`, команду сборки `npm ci && npm run build` и каталог публикации `dist`. Root Directory оставить пустым: содержимое локальной папки `project` находится в корне репозитория. Версия Node.js — 24.11.0. Эти настройки также записаны в `render.yaml`.

Обновление сайта происходит после отправки изменений в GitHub при включённом автодеплое Render.

Описание заголовков: [PNG](https://www.w3.org/TR/png-3/), [JPEG/JFIF](https://www.w3.org/Graphics/JPEG/jfif.pdf).
