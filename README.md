# Photoshop — лабораторная работа №2

Волков Роман Сергеевич, группа 221-322. GitHub: [tonnimause](https://github.com/tonnimause).

Лабораторная по работе с изображениями. Можно загрузить картинку, посмотреть её размер и глубину цвета, увеличить или уменьшить её.

## Что есть в этой версии

Поддерживаются PNG, JPG и GrayBit-7 (`.gb7`). Информация о картинке показывается в нижней панели. Там же меняется масштаб просмотра — от 12% до 300%.

Через кнопку «Изменить размер» можно задать ширину и высоту в пикселях или процентах. Пропорции сохраняются, если не убрать галочку. Для изменения размера есть два метода: ближайший сосед и билинейная интерполяция.

Проект на React и TypeScript. Компоненты интерфейса — Ant Design, стили — SCSS, сборка — Vite.

## Как запустить

Для запуска нужны Node.js и npm. В терминале из папки проекта:

```bash
npm ci
npm run dev
```

Адрес для открытия в браузере появится в терминале.

Собрать проект: `npm run build`. Запустить собранную версию: `npm run preview`.
