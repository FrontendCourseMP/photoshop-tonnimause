# Цифровое представление изображения

Волков Роман Сергеевич, группа 221-322. GitHub: [tonnimause](https://github.com/tonnimause).

В первой части реализованы загрузка PNG/JPG, отображение на canvas и сведения об исходном файле. Изображение можно вписать в рабочую область или просмотреть в масштабе 100%. Увеличенные изображения доступны через прокрутку.

## Запуск

Необходимы Node.js 24 и npm. Открыть терминал в папке `project` и выполнить:

```bash
npm ci
npm run dev
```

Перейти по адресу из терминала. Для сборки выполнить `npm run build`, для просмотра сборки — `npm run preview`.

Глубина цвета читается из заголовка исходного файла, а не из RGBA-буфера canvas. Альфа указывается отдельно. Для PNG с палитрой показывается разрядность индекса палитры; прозрачность через `tRNS` не считается отдельным альфа-каналом. JPEG с четырьмя цветовыми компонентами также не считается изображением с альфой.

PNG и JPEG декодируются средствами браузера. При отображении 16-битного PNG браузер переводит значения в свой буфер; сведения об исходной разрядности сохраняются. При наличии EXIF-ориентации браузер может повернуть изображение для просмотра, при этом строка состояния показывает размеры из заголовка.

Ограничения загрузки: 50 МБ, 24 миллиона пикселей, не более 16 384 пикселей по стороне.

Следующие части: кодер/декодер GB7 и скачивание файлов; затем проверка на наборе изображений и публикация. Ссылка на новую версию будет добавлена после её размещения.

Описание заголовков: [PNG](https://www.w3.org/TR/png-3/), [JPEG/JFIF](https://www.w3.org/Graphics/JPEG/jfif.pdf).
