# Фильтрация

Работа разбита на четыре части: расчёты фильтров, фоновое выполнение, диалог с предпросмотром, совместные проверки и публикация. Коммиты согласуются отдельно.

Первая часть реализует независимые от DOM функции в `src/image/filters.ts`. Предустановки: тождественное ядро, резкость, Гаусс 3 × 3, прямоугольное размытие и два направленных ядра Прюитта. Медианный фильтр 3 × 3, упомянутый в общей задаче, реализован отдельным режимом, не свёрткой.

Свёртка разворачивает ядро на 180 градусов. Гаусс нормирован на 16, прямоугольное размытие — на 9; пользовательское ядро автоматически не нормируется. Результат суммируется в числах с плавающей точкой, округляется и ограничивается диапазоном 0–255. Отрицательный результат Прюитта становится нулём, положительный выше 255 — 255; модуль и объединённая величина градиента не вычисляются.

Края расширяются виртуально на один пиксель: ноль для чёрного заполнения, 255 для белого, ближайший граничный пиксель для копирования. Эти правила действуют на каждый выбранный канал, в том числе альфу, если она выбрана. Размеры результата сохраняются. RGB обрабатывается покомпонентно без взвешивания по альфе, включая скрытый цвет; невыбранные каналы копируются без изменений.

Исходный массив не изменяется. `prepareFilter` создаёт отдельный результат и позволяет рассчитывать его по диапазонам строк. Это основа для фонового выполнения и отмены. Синхронный `filterRaster` используется в модульных тестах; к интерфейсу на первой стадии фильтры не подключены.

Валидация проверяет размеры и длину растра, выбранные режимы и девять конечных коэффициентов в пределах от −1000 до 1000. Ограничение коэффициентов будет показано в диалоге.
