# Уровни и гистограмма

Первая часть: диалог «Уровни» с гистограммой исходного изображения, выбором Master или отдельного канала и переключением линейной и логарифмической шкал. Гистограмма построена собственным кодом, без библиотеки диаграмм.

Master использует относительную светлоту: линеаризация sRGB, затем веса 0,2126, 0,7152 и 0,0722. Порог линеаризации 0,04045 взят из исправления в [источнике задания](https://www.w3.org/WAI/GL/wiki/Relative_luminance). Результат округляется до ближайшего уровня. Для GB7 доступно 128 уровней, для декодированных PNG и JPEG — 256. Отдельные каналы считаются по значениям компонентов без линеаризации. Прозрачные пиксели учитываются наравне с остальными; альфа не служит весом.

Логарифмический режим использует log(1 + количество), поэтому пустые столбцы остаются нулевыми. Он изменяет только высоту столбцов, не сами частоты. Отключение каналов просмотра не влияет на гистограмму.

Следующие части: три маркера входных уровней с ограничениями и отдельными настройками каналов, LUT, предпросмотр с requestAnimationFrame, сброс, отмена и применение. В первой части диалог только показывает гистограммы и не изменяет изображение. Публикация будет выполнена отдельно после согласования.
