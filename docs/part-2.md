# GB7 и сохранение

Добавлены чистые функции чтения и записи GB7. Они работают с байтами и пикселями, без canvas и сторонних библиотек обработки изображений. PNG/JPEG сохраняются браузерным кодировщиком.

Правила GB7:

- Сигнатура `47 42 37 1D`, версия 1, зарезервированные биты и байты — нули.
- Длина файла строго равна `12 + ширина × высота`, размеры — unsigned 16-bit big-endian.
- Биты 0–6 хранят яркость, бит 7 — бинарную маску. При отсутствии маски старший бит должен быть нулевым, все пиксели непрозрачны.
- При чтении яркость переводится в диапазон canvas по формуле `round(gray7 × 255 / 127)`.
- При записи серое вычисляется как `0.299R + 0.587G + 0.114B`, затем `round(gray8 × 127 / 255)`.
- При включённой маске альфа 0–127 становится прозрачной, 128–255 — непрозрачной. При выключенной маске RGB сначала объединяется с белым фоном.
- Яркость замаскированных пикселей хранится в документе и не теряется при повторном сохранении GB7. Canvas используется только для отображения.

Проверены 57 модульных тестов и 19 браузерных сценариев, включая:

- Все 128 уровней серого и 256 возможных байтов с маской, точное восстановление исходных байтов GB7.
- Проверка записанного заголовка по заранее известным байтам, а не только через собственный декодер.
- Ошибочные сигнатуры, версии, флаги, резерв, размеры и длина файла.
- Девять сочетаний PNG/JPG/GB7 на входе и выходе, настоящие скачивания и повторная загрузка.
- Сохранение полного разрешения, исходных пикселей и прозрачности документа после экспорта.
- Белый фон JPEG, отключение маски GB7, запрет сохранения до загрузки.
- Сообщение об ошибке кодировщика, клавиатурное закрытие и возврат фокуса, окно сохранения на ширине 360 px.

Дополнительно проверены предоставленные файлы `vertical-kapibara.gb7`, `kapibara-mask.gb7` и `gradient-half-mask.gb7`: заголовки, отображение, количество прозрачных пикселей и побайтовое совпадение при повторном сохранении. Их копии находятся в `tests/fixtures/gb7`.
