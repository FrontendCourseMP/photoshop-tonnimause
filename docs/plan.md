# План работы

1. Основа интерфейса, загрузка PNG/JPEG, canvas, исходные размеры и глубина цвета. Проверки заголовков и основных сценариев загрузки.
2. GrayBit-7: собственное чтение/запись, загрузка, скачивание PNG/JPEG/GB7. Явно задать преобразование RGB в серый и полупрозрачности в бинарную маску. Проверить граничные значения и обратное преобразование.
3. Полный набор файлов, включая образцы LMS; проверки экспорта и повторной загрузки, разных размеров изображения и viewport, исправления, README и Render.

Каждая часть завершается отдельным согласованным коммитом. До согласования не коммитить и не публиковать. Историю не переписывать.

В задании GB7 маска сначала описана как бит 7, затем ошибочно названа битом 0. Рабочая трактовка: биты 0–6 — серый, бит 7 — маска; при флаге 0 старший бит равен 0. Проверить на образцах LMS до завершения второго этапа.

Папка reference находится вне репозитория и служит только справкой. Новая реализация строится по требованиям задания.
